# Reglas del proyecto

- Comentarios cortos, que describan el código tal como está (no su historia ni cambios pasados).
- Mensajes de commit de una sola línea.
- Reportes al usuario de máximo 5 líneas.
- Nunca hacer push directo a la rama principal (`main` / `claude/new-session-psu3ud`): siempre rama aparte y pull request.
